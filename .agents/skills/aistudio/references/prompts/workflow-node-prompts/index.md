# Workflow Node Prompts

Read the node prompt files relevant to the workflow node types you are creating, editing, validating, or debugging.
These files mirror the Workflow Builder vibe agent node prompt modules.

- `start-end.md`: START and END internal node rules.
- `llm.md`: LLM node prompt, input, and output contract rules.
- `agent.md`: Agent node rules.
- `rag-document-tool.md`: RAG Document Tool node rules.
- `workflow.md`: Workflow node rules.
- `code.md`: Code node rules.
- `set-variables.md`: Set Variables node rules.
- `if-condition.md`: If Condition node rules.
- `switch.md`: Switch node rules.
- `for-loop.md`: For Loop node rules.
- `while-loop.md`: While Loop node rules.
- `wait.md`: Wait node rules.
- `human-approval.md`: Human Approval node rules.
- `parallel.md`: Parallel node rules.
- `reference.md`: Reference node rules.
- `reference-block.md`: Reference Block node rules.
- `return.md`: Return node rules.
- `email.md`: Email node rules.
- `bo-function.md`: BO Function node rules.
- `document-processor.md`: Document Processor node rules.
- `external-rest.md`: External REST node rules.
- `tool.md`: Tool node rules.
- `vector-db-reader.md`: Vector DB Reader node rules.
- `vector-db-writer.md`: Vector DB Writer node rules.
- `comment-diagram-only.md`: Diagram-only comment node rules.
