# Business Objects

## Business Object : Career development skills lookup

| **Name** | Career development skills lookup |
|---------------|---------------|
| **Code** | ORA_HCM_CAREER_XX_CAREERDEVELOPMENTSKILLSLOOKUP |
| **Description** | The Career development skills lookup Business Object provides access to records of skills currently in development for the logged-in user. It supports retrieval operations to help users identify and track their ongoing career development skills within the HCM Career product. |


### Functions

#### Function : getSkillsInDevelopment
Description : Business object function to get the list of skills currently in development for the logged in user

| **Parameter Name** | **Description**|
|---------------|---------------|
| personId | Person id of the person whose skills in development should be retrieved. |
